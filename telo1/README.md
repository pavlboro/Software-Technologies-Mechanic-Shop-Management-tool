# Συνεργείο Auto - Εφαρμογή διαχείρισης γενικού συνεργείου

Εφαρμογή web (client-server) σε **Python** με **Flask** και **SQLite**.
Υποστηρίζει Python 3.9 έως 3.13 (συμβατή με 3.13, χωρίς νεότερες απαιτήσεις).

## Οδηγίες εκτέλεσης στο PyCharm

1. Αποσυμπιέστε τον φάκελο και ανοίξτε τον στο PyCharm (File > Open).
2. File > Settings > Project > Python Interpreter: επιλέξτε Python 3.13 (ή 3.11 / 3.12).
3. Στο Terminal του PyCharm:  pip install -r requirements.txt
4. Δεξί κλικ στο app.py > Run 'app'.
5. Ανοίξτε στον browser:  http://127.0.0.1:5000

Η βάση δεδομένων (synergeio.db) δημιουργείται αυτόματα με δοκιμαστικά δεδομένα
την πρώτη εκτέλεση. Για επαναφορά δεδομένων: διαγράψτε το αρχείο synergeio.db.

## Αντιστοίχιση με την εκφώνηση

- Ρόλοι και δικαιώματα: Ιδιοκτήτης, Υπάλληλος Υποδοχής, Μηχανικός.
- Οθόνη σύνδεσης, πίνακας ελέγχου ανά ρόλο, αναζήτηση με 10 κριτήρια και εκτύπωση.
- Πελάτες με συσχετισμένα οχήματα και εκτύπωση καρτέλας.
- Καρτέλα οχήματος με τεχνικά στοιχεία, τρέχουσα ένδειξη, πίνακα διαχρονικής
  μεταβολής χιλιομέτρων και πλήρες ιστορικό service.
- Άνοιγμα δελτίου με υποχρεωτική αιτιολόγηση σε μικρότερη ένδειξη χιλιομέτρων
  και φωτογραφίες παραλαβής (κάμερα κινητού μέσω του πεδίου αρχείου).
- Κλείσιμο δελτίου με παραστατικό, αυτόματη ανάλυση κόστους με ΦΠΑ 24%,
  εκτύπωση και αποστολή e-mail (SMTP).
- Επεξεργασία τεχνικών εργασιών από τον μηχανικό, με πρότυπα εργασιών,
  ανταλλακτικά από τον κατάλογο, ώρες εργασίας, φωτογραφίες και σημειώσεις.
- Κατάλογος ανταλλακτικών με χειροκίνητη καταχώριση και εισαγωγή CSV έως 20MB.
- Ρυθμίσεις ιδιοκτήτη: χρήστες και ρόλοι, ωριαία χρέωση, πρότυπα εργασιών, SMTP.
- Εκτυπώσεις μέσω του λειτουργικού (CSS @media print) για δελτία, καρτέλες και λίστες.
- Ασφάλεια: κωδικοί με hash (Werkzeug), συνεδρίες, έλεγχος ρόλου σε κάθε διαδρομή.
